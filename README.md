# Persian Gulf normality odds

Longitudinal dashboard of daily Grok superforecasts on a return to **functional normality** in the Persian Gulf after the 2026 Iran War (18 Mar – 15 Nov 2026).

## Live dashboard

**https://tripp-smith.github.io/iran-forecast/**

## Rebuild locally

```bash
python3 util/parse_forecasts.py
```

Writes `analysis/grok_iran_forecast.html` and `docs/index.html` (GitHub Pages).

## Publish

```bash
./util/publish_pages.sh
```

Optional legacy gist preview: `./util/publish_gist.sh`
